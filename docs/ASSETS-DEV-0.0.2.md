# Währungsassets dev-0.0.2

Die Münzen-/Scheintexturen wurden mit dem eingebauten Bildgenerator als einzelner 4×4-Atlas auf transparentem Hintergrund erstellt und anschließend in 16 Vorder-/Rückseiten für acht Geldgegenstände getrennt. Die vollständigen PNG-Dateien liegen unter `src/main/resources/assets/ng_city/textures/item/`; die Itemmodelle verwenden unterschiedliche Vorder-/Rückseiten.

Gestaltungsvorgabe: flache, originalnah gravierte Euro-Münzen, goldene 10/20/50-Cent-Münzen, zweifarbige 1-/2-Euro-Münzen; rote 10-, blaue 20- und orange 50-Euro-Scheine mit europäischen Architekturmotiven und NG-WÄHRUNG-Schriftzug. Keine weiteren Stückelungen. Werkzeug: eingebauter Bildgenerator. Grafikvorschauen wurden angesehen; ein realer Minecraft-Clienttest steht noch aus.

Geldbörse, Kreditkarte, Schlüssel sowie Gerätebeschriftungen wurden als deterministische Spiel-/UI-Texturen mit dem Projekt erstellt. Es werden keine Vanilla-Texturen kopiert ausgeliefert; Türmodelle referenzieren die vorhandenen Minecraft-Ressourcen.
