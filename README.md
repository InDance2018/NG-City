# NG-City

NG-City bildet die geplante Grundlage für eine vollständige NeverGate-Stadt und ihr gemeinsames Wirtschaftssystem.

## Planung

Die [Grundlagenplanung](PLANUNG.md) hält die vereinbarten Architekturentscheidungen fest.

- NG-Verkehr und NG-Fahrzeuge bleiben eigenständig ohne NG-City nutzbar.
- Wirtschaftsfunktionen greifen ausschließlich mit zusätzlich installierter NG-City.
- Alle beteiligten NG-Mods nutzen dann dieselbe zentrale Wirtschaftsgrundlage.
- Weitere Projekte können später angebunden werden.

**Stand: 18.10.2026 · Planung.** Noch kein Mod-Build und keine gemeinsame Wirtschaftsanbindung implementiert oder geprüft. Der konkrete Funktionsumfang wird weiter besprochen.
